I’m Daniela Paneva—an interactive front-end developer based in Sofia, Bulgaria.

I build fluid digital spaces that live at the intersection of motion, logic, and visual art. Driven by a deep fascination with creative coding and WebGL, I treat the browser window as an interactive canvas rather than a static grid. I focus on engineering lightweight, highly responsive user experiences where every layout transition and micro-interaction feels deliberate, heavy, and natural.

This portfolio itself operates as a dynamic visual homage to the liquid, psychedelic visualizers of Red Hot Chili Peppers’ album, “Return of the Dream Canteen”—translating continuous analog organic morphing into real-time WebGL shader code.

Technical platform Vanilla JavaScript / WebGL / Three.js / CSS architecture / Creative layout strategy
